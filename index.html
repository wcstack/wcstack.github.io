Packages

Three packages, one philosophy

3つのパッケージ、1つの設計思想

@wcstack/autoloader

Component Autoloader

Automatically detects custom elements in the DOM and dynamically imports them via Import Maps. Supports eager & lazy loading with MutationObserver for dynamically added elements.

  • Import Maps
  • Eager / Lazy
  • MutationObserver
  • Pluggable Loaders
  • Lit Compatible
@wcstack/router

Declarative Router

Define SPA routes directly in HTML with nested layouts, typed URL parameters (:id(int)), route guards, and per-route <head> management. Built on the Navigation API.

  • Nested Routes
  • Typed Params
  • Layouts
  • Route Guards
  • Head Management
@wcstack/state

Reactive State

Reactive state management with Mustache syntax, path getters for computed properties, 37 built-in filters, two-way binding, and structural directives — no virtual DOM or compilation.

  • Mustache Syntax
  • Path Getters
  • 37 Filters
  • Two-way Binding
  • for / if / else

See it in action

Code that reads like HTML

HTMLのように読めるコード

index.html Autoloader 
<!-- Define your import maps -->
<script type="importmap">
  {
    "imports": {
      "@components/ui/": "./components/ui/",
      "@components/ui|lit/": "./components/ui-lit/"
    }
  }
</script>

<!-- Auto-loaded from ./components/ui/button.js -->
<ui-button></ui-button>

<!-- Auto-loaded with Lit loader -->
<ui-lit-card></ui-lit-card>
index.html Router 
<wcs-router>
  <template>
    <wcs-route path="/">
      <wcs-layout layout="main-layout">
        <nav slot="header">
          <wcs-link to="/">Home</wcs-link>
          <wcs-link to="/products">Products</wcs-link>
        </nav>
        <wcs-route index>
          <wcs-head><title>Home</title></wcs-head>
          <app-home></app-home>
        </wcs-route>
        <wcs-route path="products">
          <wcs-route path=":id(int)">
            <product-detail data-bind="props"></product-detail>
          </wcs-route>
        </wcs-route>
      </wcs-layout>
    </wcs-route>
    <wcs-route fallback>
      <error-404></error-404>
    </wcs-route>
  </template>
</wcs-router>
<wcs-outlet></wcs-outlet>
index.html State 
<wcs-state>
  <script type="module">
    export default {
      taxRate: 0.1,
      cart: {
        items: [
          { name: "Widget", price: 500, quantity: 2 },
          { name: "Gadget", price: 1200, quantity: 1 }
        ]
      },
      get "cart.total"() {
        return this.$getAll("cart.items.*.subtotal", [])
          .reduce((a, b) => a + b, 0);
      }
    };
  </script>
</wcs-state>

<!-- Declarative rendering with Mustache syntax -->
<template data-wcs="for: cart.items">
  <div>
    {{ .name }} &times;
    <input type="number" data-wcs="value: .quantity">
    = <span data-wcs="textContent: .subtotal|locale"></span>
  </div>
</template>
<p>Total: <span data-wcs="textContent: cart.total|locale(ja-JP)"></span></p>

Quick Start

Up and running in minutes

数分で使い始められます

index.html CDN via jsdelivr 
<!-- Load from jsdelivr CDN -->
<script src="https://cdn.jsdelivr.net/gh/wcstack/wcstack@main/packages/autoloader/dist/auto.min.js"></script>
<script src="https://cdn.jsdelivr.net/gh/wcstack/wcstack@main/packages/router/dist/auto.min.js"></script>
<script src="https://cdn.jsdelivr.net/gh/wcstack/wcstack@main/packages/state/dist/auto.min.js"></script>
1

Add Script Tags

Add <script> tags pointing to the jsdelivr CDN. No install or build needed.

2

Pick What You Need

Each package is independent. Include only the ones you need — one, two, or all three.

3

Write HTML

Use custom elements directly in your HTML. The autoloader handles the rest — just write <my-component>.
