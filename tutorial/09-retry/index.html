How it worksしくみ

Three outputs, three keys3つの出力と3つのキー

A request is in one of three conditions — on its way, failed, arrived — and <wcs-fetch> reports each as a property: loading, error and value. Each lands in its own key, and each line of the page reads one of them. When the file is missing, error becomes an error object (an HTTP error carries the status code) and value goes back to null, so catalog is null, the shop stays hidden and products is still an empty list. hidden: loadError|not shows the line while there is an error. When a later request succeeds, error is null again and the line goes away by itself.

リクエストは3つの状態(届く途中・失敗・届いた)のどれかにあり、<wcs-fetch>はそれぞれをプロパティで知らせます。loading・error・valueです。それぞれが自分のキーに入り、ページの各行はそのどれかを読みます。ファイルが無いと、errorはエラーのオブジェクト(HTTPのエラーならステータスコードを持つ)になり、valueはnullに戻ります。だからcatalogはnullで、ショップは隠れたまま、productsは空のリストのままです。hidden: loadError|notは、エラーがある間その行を表示します。後のリクエストが成功するとerrorはnullに戻り、行はひとりでに消えます。

A command written as a value値として書いた命令

trigger is an input that means “run now”: writing true to it starts the request again. So retry only assigns this.reload = true, and trigger: reload carries it to the element. When the request is done, the element sets trigger back to false and announces it, which brings reload back to false, ready for the next press. Your code never holds the element or calls a method on it; it changes state, as everywhere else.

triggerは「今実行して」を意味する入力で、trueを書き込むとリクエストがもう一度始まります。だからretryはthis.reload = trueと代入するだけで、trigger: reloadがそれを要素へ運びます。リクエストが終わると、要素はtriggerをfalseに戻してそれを知らせ、reloadもfalseに戻って、次に押されるのを待ちます。コードは要素をつかむことも、そのメソッドを呼ぶこともありません。ほかの場所と同じく、stateを変えるだけです。

Common mistakesよくある間違い

Binding only valuevalueだけをバインドする

That was the page of step 8. When the request fails, value goes back to null and the shop simply never appears — no message, nothing to press, and only the console knows why. Whenever you bind value, bind error too.

それがステップ8のページでした。リクエストが失敗するとvalueはnullに戻り、ショップは現れないままです。メッセージも押すものも無く、理由を知っているのはコンソールだけです。valueをバインドするときは、errorも必ずバインドします。

Starting the trigger at truetriggerをtrueで始める

reload: true fires as soon as the binding is made, so the catalog is requested twice at startup. A trigger has no memory of what it was; any true it is given runs the request. The checker knows:

reload: trueはバインドした瞬間に発火するので、起動時に商品一覧を2回取りに行きます。triggerは前の値を覚えておらず、渡されたtrueはどれもリクエストを実行します。検査器はこれを知っています。

  <script type="module" src="https://esm.run/@wcstack/fetch@4/auto"></script>

<wcs-state>
  <script type="module">
    /** @typedef {{ id: number, name: string, category: string, description: string, price: number, stock: number, icon: string }} Product */

    export default {
      /** @type {Product[] | null} */
      catalog: null,
      loading: false,
      loadError: null,
      reload: false,
      cart: [],
      query: "",
      category: "all",

      get products() {
        return this.catalog ?? [];
      },
      get catalogReady() {
        return this.catalog !== null;
      },
      get "products.*.matches"() {
        const query = this.query.trim().toLowerCase();
        return (this.category === "all" || this["products.*.category"] === this.category) &&
          this["products.*.name"].toLowerCase().includes(query);
      },
      get matchCount() {
        return this.$getAll("products.*.matches", []).filter(Boolean).length;
      },

      get "cart.*.lineTotal"() {
        return this["cart.*.price"] * this["cart.*.quantity"];
      },
      get itemCount() {
        return this.$getAll("cart.*.quantity", []).reduce((sum, n) => sum + n, 0);
      },
      get subtotal() {
        return this.$getAll("cart.*.lineTotal", []).reduce((sum, n) => sum + n, 0);
      },
      get shipping() {
        return this.subtotal >= 50 ? 0 : 5;
      },
      get total() {
        return this.subtotal + this.shipping;
      },

      retry() {
        this.reload = true;
      },
      addToCart(event, index) {
        const product = this.products[index];
        const line = this.cart.findIndex(item => item.id === product.id);
        if (line >= 0) {
          this[`cart.${line}.quantity`] += 1;
        } else {
          this.cart = this.cart.concat({ id: product.id, name: product.name, price: product.price, quantity: 1 });
        }
      },
      increase(event, index) {
        this[`cart.${index}.quantity`] += 1;
      },
      decrease(event, index) {
        this[`cart.${index}.quantity`] -= 1;
      },
      remove(event, index) {
        this.cart = this.cart.toSpliced(index, 1);
      }
    };
  </script>
</wcs-state>
