How it worksしくみ

Handlers receive the row indexハンドラは行のインデックスを受け取る

A handler gets the event first and, when its element sits inside a for: row, the row's index second. addToCart(event, index) receives 0 from House Blend's button, 1 from Ethiopia Yirgacheffe's, and so on, and reads the product with this.products[index] — reading through this is plain JavaScript.

ハンドラは1つ目の引数にイベントを、要素がfor:の行の中にあれば2つ目に行のインデックスを受け取ります。addToCart(event, index)は、House Blendのボタンからは0を、Ethiopia Yirgacheffeのボタンからは1を受け取り、this.products[index]で商品を読みます。thisを通した読み取りは、ふつうのJavaScriptです。

Assign a new array新しい配列を代入する

this.cart.concat({ … }) builds a new array with one more line, and this.cart = … assigns it to the path cart. As in step 1, the assignment is the update: the cart list and the badge — cart.length is a path too — render again. push would change the array in place without any assignment, and the page would not move. Use the methods that return a new array: concat, toSpliced, filter, map, toSorted, toReversed, with.

this.cart.concat({ … })は1行多い新しい配列を作り、this.cart = …がそれをパスcartに代入します。ステップ1と同じく、代入が更新です。カートの一覧とバッジ(cart.lengthもパスです)が描き直されます。pushは代入をせずに配列をその場で変えるので、ページは動きません。新しい配列を返すメソッドを使います:concat、toSpliced、filter、map、toSorted、toReversed、with。

Rows follow their objects行はオブジェクトについていく

When the new array arrives, wcstack matches the rows already on screen to their objects. The new array still holds the same line objects, so the existing lines stay exactly as they are and only the new line is created. There is no key attribute to write.

新しい配列が届くと、wcstackは画面にある行をそれぞれのオブジェクトと照らし合わせます。新しい配列も同じ行のオブジェクトを持っているので、既存の行はそのまま残り、作られるのは新しい行だけです。key属性を書く必要はありません。

Common mistakesよくある間違い

push and other in-place methodspushなどその場で変えるメソッド

this.cart.push(item) changes the array without assigning to cart, so nothing on the page updates. splice, sort and reverse do the same. The checker catches all of them as an error:

this.cart.push(item)はcartに代入せずに配列を変えるので、ページは何も更新されません。splice・sort・reverseも同じです。検査器はこれらをすべてエラーとして見つけます。

npx @wcstack/lint index.html
error wcs/array-mutation Destructive array method "push" does not trigger a reactive update (re-assigning the same reference does not reflect added/removed elements either). Use a non-destructive method with reassignment (e.g. this.cart = this.cart.concat(item)).

The index is the second argumentインデックスは2つ目の引数

Writing addToCart(index) puts the event into index, and this.products[index] is then undefined. Keep event as the first parameter even when you don't use it.

addToCart(index)と書くとindexにイベントが入り、this.products[index]はundefinedになります。使わなくても、1つ目の引数はeventのまま残します。
