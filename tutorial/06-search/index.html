query: "",
category: "all",

get "products.*.matches"() {
  const query = this.query.trim().toLowerCase();
  return (this.category === "all" || this["products.*.category"] === this.category) &&
    this["products.*.name"].toLowerCase().includes(query);
},
get matchCount() {
  return this.$getAll("products.*.matches", []).filter(Boolean).length;
},

How it worksしくみ

Two-way bindings双方向バインディング

On an <input>, value: query works in both directions: every keystroke (the input event) writes the text to query, and assigning query in code writes it back into the box. radio: category binds a group of radio buttons to one value — the checked button's value — and checks the button whose value equals the state, which is why “All” starts checked. A <select> with value: and a checkbox with checked: work the same way.

<input>のvalue: queryは両方向に働きます。打鍵のたび(inputイベント)に文字列をqueryへ書き込み、コードでqueryに代入すると入力欄に書き戻します。radio: categoryはラジオボタンの組を1つの値(チェックされたボタンのvalue)にバインドし、stateとvalueが等しいボタンにチェックを付けます。「All」が最初からチェックされているのはそのためです。<select>のvalue:やチェックボックスのchecked:も同じように働きます。

A row getter can read anything行getterは何でも読める

get "products.*.matches"() combines the row's own category and name with the top-level query and category. wcstack records all of them as dependencies of every row, so a keystroke re-evaluates matches on each product, and only the hidden flags whose value changed are written to the page.

get "products.*.matches"()は、行自身のcategoryとnameに、トップレベルのqueryとcategoryを組み合わせます。wcstackはそのすべてを各行の依存として記録するので、1打鍵ごとに各商品のmatchesが評価し直され、値が変わったhiddenだけがページに書き込まれます。

Hide, don't rebuild作り直さずに隠す

hidden: .matches|not hides the card when it doesn't match — not turns true into false and back. The cards stay in the page, so the index that addToCart receives still points into products, and the handler did not have to change. matchCount counts the matches with $getAll, and the message shows when it is 0.

hidden: .matches|notは、条件に合わないカードを隠します(notはtrueとfalseを反転します)。カードはページに残っているので、addToCartが受け取るindexは今もproductsのインデックスのままで、ハンドラを変える必要はありませんでした。matchCountは$getAllで一致した数を数え、それが0のときにメッセージを出します。

Try itやってみよう

Search the descriptions too. Change the last line of matches to (this["products.*.name"] + " " + this["products.*.description"]).toLowerCase().includes(query); and type “lemon”: Ethiopia Yirgacheffe is found by its tasting notes.

説明文も検索の対象にしてみましょう。matchesの最後の行を(this["products.*.name"] + " " + this["products.*.description"]).toLowerCase().includes(query);に変えて「lemon」と打つと、Ethiopia Yirgacheffeが味の説明から見つかります。

Common mistakesよくある間違い

A filter on for:for:にフィルタ

for: takes no filters. A row is named by its position in the list it loops over, so the rows of a filtered copy would name other elements, and a write through a row would land on the wrong product. The page refuses to start, and the checker says why:

for:はフィルタを取りません。行は回しているリストの中の位置で名指されるので、絞り込んだコピーの行は別の要素を指してしまい、行を通した書き込みが違う商品に届いてしまいます。ページは起動せず、検査器がその理由を示します。

npx @wcstack/lint index.html
error wcs/binding-syntax Binding syntax error (the runtime throws at load time): "for: products|not": "for:" takes no filters — a row is "<path>.<index>", so the rows of a filtered list would name other elements. Declare a getter that returns the filtered list and loop over it ("for: <getter>").

Numbers from inputs are strings入力から来る数値は文字列

value: always writes a string. Bind a quantity box with value: qty and you get "2" — and "2" + 1 is "21". For numbers, bind valueAsNumber: qty, or convert on the way in with an input filter on the left side: value|number: qty.

value:が書き込むのは常に文字列です。数量の欄をvalue: qtyでバインドすると"2"が入り、"2" + 1は"21"になります。数値はvalueAsNumber: qtyでバインドするか、左辺に入力フィルタを付けて入口で変換します(value|number: qty)。

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Little Roastery</title>
  <link rel="stylesheet" href="https://wcstack.github.io/tutorial/shop.css">
  <script type="module" src="https://esm.run/@wcstack/state@4/auto"></script>
</head>
<body>

<wcs-state>
  <script type="module">
    export default {
      products: [
        { id: 1, name: "House Blend", category: "coffee", description: "Chocolate, caramel, a hint of citrus.", price: 14, stock: 12, icon: "☕" },
        { id: 2, name: "Ethiopia Yirgacheffe", category: "coffee", description: "Bright and floral, with jasmine and lemon.", price: 18, stock: 5, icon: "☕" },
        { id: 3, name: "Colombia Supremo", category: "coffee", description: "Nutty and smooth, with a cocoa finish.", price: 16, stock: 8, icon: "☕" },
        { id: 4, name: "Sencha", category: "tea", description: "Fresh, grassy Japanese green tea.", price: 12, stock: 20, icon: "🍵" },
        { id: 5, name: "Matcha", category: "tea", description: "Stone-ground, ceremonial grade.", price: 24, stock: 0, icon: "🍵" },
        { id: 6, name: "Measuring Spoon", category: "tools", description: "One scoop, one cup.", price: 6, stock: 30, icon: "🥄" },
        { id: 7, name: "Milk Pitcher", category: "tools", description: "Stainless steel, 350 ml.", price: 15, stock: 4, icon: "🥛" }
      ],
      cart: [],
      query: "",
      category: "all",

      get "products.*.matches"() {
        const query = this.query.trim().toLowerCase();
        return (this.category === "all" || this["products.*.category"] === this.category) &&
          this["products.*.name"].toLowerCase().includes(query);
      },
      get matchCount() {
        return this.$getAll("products.*.matches", []).filter(Boolean).length;
      },

      get "cart.*.lineTotal"() {
        return this["cart.*.price"] * this["cart.*.quantity"];
      },
      get itemCount() {
        return this.$getAll("cart.*.quantity", []).reduce((sum, n) => sum + n, 0);
      },
      get subtotal() {
        return this.$getAll("cart.*.lineTotal", []).reduce((sum, n) => sum + n, 0);
      },
      get shipping() {
        return this.subtotal >= 50 ? 0 : 5;
      },
      get total() {
        return this.subtotal + this.shipping;
      },

      addToCart(event, index) {
        const product = this.products[index];
        const line = this.cart.findIndex(item => item.id === product.id);
        if (line >= 0) {
          this[`cart.${line}.quantity`] += 1;
        } else {
          this.cart = this.cart.concat({ id: product.id, name: product.name, price: product.price, quantity: 1 });
        }
      },
      increase(event, index) {
        this[`cart.${index}.quantity`] += 1;
      },
      decrease(event, index) {
        this[`cart.${index}.quantity`] -= 1;
      },
      remove(event, index) {
        this.cart = this.cart.toSpliced(index, 1);
      }
    };
  </script>
</wcs-state>

              <span>{{ .quantity }}</span>
              <button type="button" aria-label="Increase" data-wcs="onclick: increase">+</button>
            </span>
            <button type="button" class="remove" data-wcs="onclick: remove">Remove</button>
          </li>
