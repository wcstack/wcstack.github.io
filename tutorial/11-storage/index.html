get savedCart() {

How it worksしくみ

An input whose value lives in localStorage値がlocalStorageにある入力

<wcs-storage> has one property that works both ways, value, like value: on an <input>. When the tag appears, it reads its key and announces what it found; when value is assigned, it saves it (as JSON). When another tab or frame of the same site saves the key, the new value arrives on its own — that is the browser's storage event, and it is why the two demos above follow each other.

<wcs-storage>には両方向に働くプロパティvalueが1つあり、<input>のvalue:と同じように振る舞います。タグが現れるとkeyを読んで見つけたものを知らせ、valueに代入されると(JSONとして)保存します。同じサイトの別のタブやフレームがそのキーに保存すると、新しい値がひとりでに届きます。ブラウザのstorageイベントで、上の2つのデモが互いに追従するのはそのためです。

Bind what to save, not the cartカートではなく、保存するものをバインドする

A binding is re-applied when its own path is assigned. this.cart = this.cart.concat(…) assigns cart, but this[`cart.${index}.quantity`] += 1 assigns a path under it, and a binding on cart never hears about that — bound to cart, the storage would miss every change of quantity. So the tag is bound to savedCart, a getter that reads each line's id and quantity by path, the way itemCount reads every quantity in step 5. Any change to any line re-evaluates it, the new array goes to value, and the tag saves it. The setter is the way back: a stored cart that arrives — at load, or from another tab — becomes cart.

バインディングは、自分のパスに代入されたときに当て直されます。this.cart = this.cart.concat(…)はcartに代入しますが、this[`cart.${index}.quantity`] += 1はその下のパスに代入し、cartへのバインディングはそれを知りません。cartにバインドしたら、storageは数量の変化をすべて取りこぼします。だからタグはsavedCartにバインドします。各行のIDと数量をパスで読むgetterで、ステップ5のitemCountがすべての数量を読むのと同じやり方です。どの行が変わっても評価し直され、新しい配列がvalueに渡り、タグがそれを保存します。setterは帰り道です。届いた保存済みのカート(読み込み時や、別のタブから)がcartになります。

Who goes first: #init=elementどちらが先か: #init=element

At load two values meet: the cart in localStorage, and the one the state starts with — savedCart of an empty cart, []. By default the state's value is written to the element first, and the empty cart would be saved over the stored one. #init=element makes the element win that first sync: the stored cart goes into the setter. After that, changes flow both ways as usual. On a first visit the key is empty, the element holds null, and the setter ignores anything that isn't an array.

読み込み時には2つの値が出会います。localStorageの中のカートと、stateが最初に持つ値(空のカートのsavedCart、つまり[])です。既定ではstateの値が先に要素へ書かれ、空のカートが保存済みのカートの上に保存されてしまいます。#init=elementは、最初の同期で要素を勝たせます。保存済みのカートがsetterに入ります。その後は、いつもどおり両方向に流れます。初めての訪問ではキーが空で、要素はnullを持ち、setterは配列でないものを無視します。

The stored cart arrives at once; the catalog arrives later. In between, the header's count is already right — it reads only quantities — and the lines' names would be “…”, thanks to the ?. of step 10.

保存済みのカートはすぐに届き、商品一覧は後から届きます。その間もヘッダーの個数はもう正しく(数量しか読まないから)、行の名前はステップ10の?.のおかげで「…」になります。

Try itやってみよう

Keep the chosen category for this tab. Add get savedCategory() { return this.category; } and set savedCategory(value) { if (value) this.category = value; } to the state, and <wcs-storage key="little-roastery-category" type="session" data-wcs="value#init=element: savedCategory"></wcs-storage> to the body. Pick Tea and reload: Tea is still picked. type="session" uses sessionStorage, which each tab keeps for itself.

選んだカテゴリをこのタブの間だけ残してみましょう。stateにget savedCategory() { return this.category; }とset savedCategory(value) { if (value) this.category = value; }を、bodyに<wcs-storage key="little-roastery-category" type="session" data-wcs="value#init=element: savedCategory"></wcs-storage>を加えます。Teaを選んで再読み込みしても、Teaが選ばれたままです。type="session"はsessionStorageを使い、タブごとに別々に保たれます。

Common mistakesよくある間違い

Binding the cart itselfカートそのものをバインドする

With data-wcs="value: cart", add House Blend twice: the page shows 2, and localStorage holds 1, because the second add wrote cart.0.quantity. Reload, and the cart is empty: without #init=element, the state's [] was saved over it. Nothing appears in the console. Step 12 shows the checker catching both.

data-wcs="value: cart"にしてHouse Blendを2回入れると、ページは2を表示し、localStorageには1が入っています。2回目の追加はcart.0.quantityに書いたからです。再読み込みするとカートは空です。#init=elementが無いので、stateの[]がその上に保存されました。コンソールには何も出ません。検査器が両方を見つけるところは、ステップ12で見せます。

Forgetting #init=element#init=elementを忘れる

With value: savedCart, everything works until you reload: then the cart is empty, because savedCart of the starting empty cart was saved over the stored one. The checker can't see this one — it would have to know what a getter returns at startup. Test the way the demo above invites you to: add something, then reload.

value: savedCartにすると、再読み込みするまでは問題なく動きます。再読み込みするとカートは空です。最初の空のカートのsavedCartが、保存済みのカートの上に保存されたからです。これは検査器には見えません(getterが起動時に何を返すかを知る必要があるため)。上のデモが誘うとおりに試しましょう。何かを入れて、再読み込みします。

<wcs-state>
  <script type="module">
    /** @typedef {{ id: number, name: string, category: string, description: string, price: number, stock: number, icon: string }} Product */

    export default {
      /** @type {Product[] | null} */
      catalog: null,
      loading: false,
      loadError: null,
      reload: false,
      cart: [],
      query: "",
      category: "all",

      get products() {
        return this.catalog ?? [];
      },
      get catalogReady() {
        return this.catalog !== null;
      },
      get "products.*.matches"() {
        const query = this.query.trim().toLowerCase();
        return (this.category === "all" || this["products.*.category"] === this.category) &&
          this["products.*.name"].toLowerCase().includes(query);
      },
      get matchCount() {
        return this.$getAll("products.*.matches", []).filter(Boolean).length;
      },

      get "cart.*.product"() {
        const id = this["cart.*.id"];
        return this.products.find(product => product.id === id);
      },
      get "cart.*.name"() {
        return this["cart.*.product"]?.name ?? "…";
      },
      get "cart.*.price"() {
        return this["cart.*.product"]?.price ?? 0;
      },
      get "cart.*.lineTotal"() {
        return this["cart.*.price"] * this["cart.*.quantity"];
      },
      get itemCount() {
        return this.$getAll("cart.*.quantity", []).reduce((sum, n) => sum + n, 0);
      },
      get subtotal() {
        return this.$getAll("cart.*.lineTotal", []).reduce((sum, n) => sum + n, 0);
      },
      get shipping() {
        return this.subtotal >= 50 ? 0 : 5;
      },
      get total() {
        return this.subtotal + this.shipping;
      },

      get "cart.*.saved"() {
        return { id: this["cart.*.id"], quantity: this["cart.*.quantity"] };
      },
      get savedCart() {
        return this.$getAll("cart.*.saved", []);
      },
      set savedCart(lines) {
        if (Array.isArray(lines)) this.cart = lines;
      },

      retry() {
        this.reload = true;
      },
      addToCart(event, index) {
        const product = this.products[index];
        const line = this.cart.findIndex(item => item.id === product.id);
        if (line >= 0) {
          this[`cart.${line}.quantity`] += 1;
        } else {
          this.cart = this.cart.concat({ id: product.id, quantity: 1 });
        }
      },
      increase(event, index) {
        this[`cart.${index}.quantity`] += 1;
      },
      decrease(event, index) {
        this[`cart.${index}.quantity`] -= 1;
      },
      remove(event, index) {
        this.cart = this.cart.toSpliced(index, 1);
      }
    };
  </script>
</wcs-state>
