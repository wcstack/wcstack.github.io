Build a shop with wcstackwcstackでショップを作る

Build a small online shop — a product catalog, a cart with totals, search — in one HTML file, one step at a time. No build tools and no npm install: a text editor and a browser are all you need.

商品一覧、合計の出るカート、検索のある小さなオンラインショップを、HTMLファイル1つで一歩ずつ作ります。ビルドツールもnpm installもいりません。必要なのはテキストエディタとブラウザだけです。

Before you start始める前に

  • A text editor and a modern browser. Each step is a single index.html. Save it and open it — double-clicking the file works, and so does any local server.
  • HTML and a little JavaScript: objects, arrays, functions. No framework experience is needed, and none of it carries over by accident — wcstack has no virtual DOM, no hooks and no components to learn first.
  • Node.js is optional. You need it only for the checker, npx @wcstack/lint, which step 7 introduces.
  • テキストエディタと最近のブラウザ。各ステップはindex.html1枚です。保存して開くだけで、ファイルのダブルクリックでも、ローカルサーバーでも動きます。
  • HTMLと少しのJavaScript(オブジェクト、配列、関数)。フレームワークの経験はいりません。仮想DOMもフックも、先に覚えるコンポーネントもありません。
  • Node.jsは任意です。必要なのは、ステップ7で紹介する検査器npx @wcstack/lintを使うときだけです。

How each step works各ステップの読み方

Every step starts with its page running live, so you see the goal before the code. Then come the code changes — only what changed, starting from your page of the previous step — and How it works, which explains the new ideas in a few paragraphs. Try it suggests one change to make yourself, and Common mistakes shows what goes wrong and how it looks. If you lose track, the complete file of each step is at the bottom of its page.

どのステップも、そのページが動いている様子から始まるので、コードより先にゴールが見えます。続いてコードの変更(前のステップの自分のページからの差分だけ)と、新しい考え方を数段落で説明する「しくみ」があります。「やってみよう」は自分で試す変更を1つ挙げ、「よくある間違い」は何がどう壊れるかを見せます。迷ったら、各ページの最後にそのステップのファイル全体があります。

Part 1 — The basicsPart 1 — 基本

Seven steps, with nothing but @wcstack/state. Each takes ten to fifteen minutes.

@wcstack/stateだけを使う7つのステップです。1つにつき10〜15分ほどです。

  1. 1 Show a product商品を1つ表示する One file, one script tag. Show a product from state and count clicks. ファイル1つ、scriptタグ1つ。stateの商品を表示し、クリックを数える。 <wcs-state>data-wcstextContent:|toFixedonclick:
  2. 2 List the catalog商品一覧を並べる Repeat a card for every product and mark the one that is sold out. 商品ごとにカードを繰り返し、売り切れの商品に印を付ける。 for:.name{{ }}class.NAME:hidden:disabled:
  3. 3 Put products in the cartカートに商品を入れる Handlers learn which row was clicked; a list changes when you assign a new array. ハンドラがどの行が押されたかを知る。リストは新しい配列を代入して変える。 (event, index)concatcart.length
  4. 4 Change quantities数量を変える Write to one cell with a path, and learn the one rule: assign to the path. パスで1つのセルに書き込み、ただ1つの規則「パスに代入する」を学ぶ。 cart.0.quantitytoSpliced|le
  5. 5 Add up the cartカートを集計する Line totals, item count, shipping and total as getters; a message for the empty cart. 小計・品数・送料・合計をgetterで。空のカートにはメッセージを。 get "cart.*.lineTotal"()$getAllif:else:
  6. 6 Search and filter検索と絞り込み Two-way bindings carry input into state; a getter on every product decides what shows. 双方向バインディングが入力をstateへ運び、各商品のgetterが表示を決める。 value:radio:|not
  7. 7 Check your pageページを検査する Catch mistyped paths, unknown filters and array mutations before you reload. パスの打ち間違い、存在しないフィルタ、配列の破壊的変更を、再読み込みの前に見つける。 npx @wcstack/lintwcstack-intellisense
