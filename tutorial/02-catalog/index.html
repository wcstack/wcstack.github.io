In the markup, replace the single card inside <main> with a section that loops over the list:

マークアップでは、<main>の中の1枚のカードを、リストを回すセクションに置き換えます。

index.html — <main>replaces the cardカードを置き換え
<main class="shop">
  <section class="catalog">
    <h2>Products</h2>
    <div class="grid">
      <template data-wcs="for: products">
        <article class="card" data-wcs="class.sold-out: .stock|eq(0)">
          <div class="card-icon">{{ .icon }}</div>
          <h3>{{ .name }}</h3>
          <p>{{ .description }}</p>
          <p class="price">${{ .price|toFixed(2) }}</p>
          <p class="badge" data-wcs="hidden: .stock|ne(0)">Sold out</p>
          <button type="button" data-wcs="onclick: addToCart; disabled: .stock|eq(0)">Add to cart</button>
        </article>
      </template>
    </div>
  </section>
</main>

How it worksしくみ

for: repeats a templatefor:はテンプレートを繰り返す

The standard <template> element is inert: the browser parses it but shows nothing. data-wcs="for: products" turns it into a loop. Its content is copied once for every element of products and placed right after the template. When the array changes later, only the cards that changed are added or removed.

標準の<template>要素は不活性で、ブラウザはパースするだけで何も表示しません。data-wcs="for: products"がこれをループにします。中身がproductsの要素ごとに1回ずつ複製され、テンプレートのすぐ後ろに置かれます。あとで配列が変わったときは、変わったカードだけが足されたり取り除かれたりします。

.name means “this row's name”.nameは「この行のname」

Inside the loop, .name is short for products.*.name. The * stands for “the row this element belongs to”. A row never stores its index or a reference to its object; it holds only the wildcard path, and wcstack supplies the index. It is the same contract as in step 1 — a path — with one segment left open.

ループの中の.nameはproducts.*.nameの省略形です。*は「この要素が属する行」を表します。行は自分のインデックスもオブジェクトへの参照も持たず、ワイルドカードのパスだけを持っていて、インデックスはwcstackが補います。ステップ1と同じ「パス」という契約で、1つの区間だけが空いている形です。

{{ }} inside templatesテンプレートの中の{{ }}

{{ .name }} is a text binding, the same as textContent: .name on a wrapper element. Inside a template nothing is visible until the row is rendered, so the braces never flash on screen. A {{ }} takes filters too: {{ .price|toFixed(2) }}.

{{ .name }}はテキストのバインディングで、包む要素にtextContent: .nameと書くのと同じです。テンプレートの中は行が描画されるまで何も見えないので、波括弧が画面にちらつくことはありません。{{ }}にもフィルタが使えます({{ .price|toFixed(2) }})。

Any property, through a filterどのプロパティにも、フィルタを通して

class.sold-out: .stock|eq(0) adds the class sold-out while the row's stock equals 0 and removes it otherwise. hidden: and disabled: are not special words: they are ordinary DOM properties, and data-wcs can set any property an element has. The comparison filters eq(0) and ne(0) turn the number into the true / false those properties expect. Several bindings on one element are separated with ;.

class.sold-out: .stock|eq(0)は、行のstockが0の間はクラスsold-outを付け、それ以外では外します。hidden:とdisabled:は特別な語ではなく、ふつうのDOMプロパティです。data-wcsは要素が持つどのプロパティにも値を入れられます。比較フィルタeq(0)・ne(0)が、数値をそれらのプロパティが期待するtrue / falseに変えます。1つの要素の複数のバインディングは;で区切ります。

One handler for every cardどのカードも同じハンドラ

Every card's button calls the same addToCart, which still only counts clicks. In the next step the handler learns which product was clicked.

どのカードのボタンも同じaddToCartを呼び、それはまだクリックを数えるだけです。次のステップで、ハンドラはどの商品が押されたかを知るようになります。

Common mistakesよくある間違い

class: without a class nameクラス名のないclass:

class: .stock|eq(0) names no class. Up to 4.0.0 it did nothing at all — it set a property named class that the browser ignores, and nothing reported it. Since 4.0.1 the state refuses it when the page loads, with [wcs/binding-syntax] … "class:" needs a class name in the console, and the checker reports it as an error. Name the class after the dot: class.sold-out:.

class: .stock|eq(0)はクラスを名指していません。4.0.0までは何も起きませんでした。ブラウザが無視するclassという名前のプロパティに値を入れるだけで、何も報告されなかったのです。4.0.1からは、ページの読み込み時にstateがこれを拒み、コンソールに[wcs/binding-syntax] … "class:" needs a class nameが出て、検査器もerrorとして報告します。クラス名はドットの後ろに書きます(class.sold-out:)。

* outside a loopループの外の*

products.*.name only means something inside for: products, where there is a row for the *. Written on the page itself, it stops the state from starting, and the console says [wcs/wildcard-rank] "products.*.name" needs 1 enclosing loop level(s); the scope provides 0.

products.*.nameが意味を持つのは、*に当てはまる行があるfor: productsの中だけです。ページに直接書くとstateが起動せず、コンソールに[wcs/wildcard-rank] "products.*.name" needs 1 enclosing loop level(s); the scope provides 0.が出ます。
